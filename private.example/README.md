# Modelo da pasta `private/`

Copie esta pasta para `private/` (que está no `.gitignore`) e preencha conforme
[docs/PERSONAL.md](../docs/PERSONAL.md). Aqui só há estrutura e dados fictícios.

- `pack/cck-pack.json`: pacote de conteúdo pessoal (formato em docs/EFFECTS.md).
- `compendium/src/`: fontes JSON do compêndio pessoal, uma pasta por compêndio.
- `compendium/text/`: texto original de cada item, colado por você (`<pacote>/<id>.html`).
- `module.personal.json`: sobreposição do manifesto para o build pessoal.
- `NOTICES.md`: avisos de licença do conteúdo copiado.
